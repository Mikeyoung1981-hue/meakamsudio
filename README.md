# meakamstudio.com

The website for Meakam Studio (games and apps by Mike Young).

## Add or change a game or app
1. Open `js/projects.js`.
2. Copy one `{ ... }` block and change the words.
3. Put pictures in `assets/projects/<id>/` (icon.png, shot-1.png, shot-2.png ...).
4. Upload the changes to GitHub. The site updates in about 1 minute.

## Pages
- index.html — home
- games.html, apps.html, upcoming.html — lists (filled in from projects.js)
- project.html?id=<id> — one game or app page
- about.html, support.html, privacy.html

## Before launch
- Change the email in `js/projects.js` (STUDIO.email).
- Have privacy.html checked.
- Add a favicon at `assets/favicon.png`.
